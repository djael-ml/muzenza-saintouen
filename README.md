# Capoeira Muzenza Saint-Ouen - Site Officiel

Bienvenue sur le dépôt du site officiel du **Groupe Muzenza de Capoeira à Saint-Ouen**. Ce projet est une application web moderne, performante et internationale conçue pour offrir une expérience utilisateur premium.

![Version](https://img.shields.io/badge/version-2.0.0-red)
![License](https://img.shields.io/badge/license-MIT-blue)
![PWA](https://img.shields.io/badge/PWA-Ready-green)

## ✨ Caractéristiques

- 🍱 **Layout Bento Moderne** : Une interface inspirée des designs contemporains avec glassmorphism et mode sombre/clair automatique.
- 🌍 **Internationalisation (i18n)** : Support complet du Français, Portugais et Anglais avec détection automatique de la langue.
- 📱 **PWA (Progressive Web App)** : Installable sur smartphone et consultable hors-ligne grâce aux Service Workers.
- ⚡ **Performance Optimisée** : Images au format WebP, minification du code source et chargement différé (lazy-loading).
- 🔒 **Sécurité & Anti-Spam** : Protection Honeypot sur les formulaires de contact et headers de sécurité Vercel.
- 📈 **SEO Avancé** : Balisage OpenGraph, Twitter Cards et données structurées JSON-LD (Schema.org).

## 🛠️ Stack Technique

- **Frontend** : HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Framework CSS** : Bootstrap 5.3.3
- **Icônes** : FontAwesome 6.4.0
- **Gestion de Formulaire** : Formspree AJAX Integration
- **Hébergement** : Optimisé pour Vercel

## 📁 Structure du Projet

```text
/
├── assets/
│   ├── css/        # Styles minifiés
│   ├── js/         # Logique (main, i18n)
│   └── images/     # Médias optimisés (WebP)
├── index.html      # Landing Page
├── infos.html      # Histoire & Graduations
├── manifest.json   # Configuration PWA
├── sw.js           # Service Worker
└── vercel.json     # Headers de sécurité
```

## 🚀 Installation & Déploiement

### Localement
Pour prévisualiser le site localement, utilisez une extension de type "Live Server" (VS Code) ou lancez simplement le fichier `index.html` dans votre navigateur.

### Déploiement Vercel
Ce projet est prêt pour Vercel. Connectez simplement votre dépôt GitHub à Vercel et le déploiement sera automatique à chaque push.
